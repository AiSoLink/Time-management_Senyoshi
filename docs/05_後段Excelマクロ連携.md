# 後段Excelマクロ連携仕様
版：3.0  更新日：2026-08-10

---

## 1. 分担
- ローカルWeb（PDF→Excel）：素材＋分割前を作る
- Excelマクロ：分割後、休息時間採用、運行間休息、ランキングを算出（上書き）

休日・週40時間・同一運行日複数運行を含む詳細要件は、
[07_後段Excelマクロ要件定義_休日週40時間.md](./07_後段Excelマクロ要件定義_休日週40時間.md) を正本とする。

---

## 2. 連携条件
- 列参照は列名（ヘッダー名）で行う
- 分割後列は空欄のまま残す（マクロが上書きする領域）
- 列順は `backend/engine/excel_headers.json` のA〜BC・55列を正本とする
- `運行ID`を一意キーとして全運行を保持する
- `運行日`は帳票日であり、暦日別労働の一意キーとして使用しない
- 同じ乗務員・同じ運行日でも、運行IDが異なる行を削除しない
